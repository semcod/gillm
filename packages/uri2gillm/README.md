# uri2gillm

`gillm://cmd/…` → linia DSL → [`dsl2gillm.dispatch()`](../dsl2gillm/README.md).

```bash
uri2gillm decode --uri 'gillm://cmd/HEALTH'
uri2gillm run --uri 'gillm://cmd/HEALTH'
uri2gillm resolve "capture screen"
```
