# nlp2gillm

Natural language → linia DSL (bez side-effect); opcjonalnie `apply` = [`dsl2gillm.dispatch()`](../dsl2gillm/README.md).

```bash
nlp2gillm to-dsl "check health"
nlp2gillm apply "capture screen"
```
